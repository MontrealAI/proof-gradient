# GoalOS Roadmap

GoalOS v10 establishes the public foundation: one catalog source of truth, one canonical public site shell, QUEBEC.AI ⚜️✨ seal/icon support, current docs, current figures, current tables, paid-artifact guard, and GitHub Actions validation.

Near-term roadmap:

1. Keep `docs/data/goalos_catalog.yml` as the single source of truth.
2. Expand GoalOS Cloud MVP 0.2 as a public browser proof without presenting it as the full SaaS.
3. Preserve and expose AEP-001 through AEP-008 public standards.
4. Convert public-safe proof into pilots, pilots into software, and software into standards.
5. Maintain the safe boundary: GoalOS does not modify base AI models.
