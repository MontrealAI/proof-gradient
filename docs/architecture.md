# Proof Gradient Production Architecture

Aim → Act → Prove → Evolve.

## Four systems

| System | Responsibility |
|---|---|
| Artifact Vault | Stores immutable, versioned reusable intelligence. |
| Run Fabric | Resolves artifacts, runs agents, emits proof. |
| Proof Ledger | Stores append-only traces, proof, evals, scores, and credit assignment. |
| Selection Gate | Evaluates, approves, canaries, monitors, promotes, pauses, and rolls back upgrades. |

Core invariant: no proof, no evolution. No eval, no propagation. No rollback, no release.
