# Civilization-Scale Intelligence Thesis

The motivating thesis:

> A superintelligent machine would be of such immense value, with so much wealth accruing to any company that owned one, that it could allow us to reach Kardashev Type II civilization level.

Proof Gradient treats this as a **strategic scenario**.

## What this repository proves now

- a large deterministic multi-agent coordination lattice
- reusable intelligence artifacts
- explicit run contracts
- append-only proof
- truth-boundary evals
- proof-required evals
- credit assignment
- typed patches
- canary selection
- rollback targets

## What this repository does not claim now

- that a superintelligent machine already exists here
- that wealth is guaranteed
- that Kardashev Type II has been reached
- that deterministic demo results equal real-world deployment results

## The honest frontier

The largest honest step is to build the evidence machinery that could coordinate and verify increasingly capable multi-agent systems without confusing ambition for proof.
