# GoalOS Engineering Roadmap

## English summary

This roadmap separates current documentation and public proof assets from future production SaaS engineering.

## Résumé français

Cette feuille de route distingue la documentation actuelle et les preuves publiques des travaux futurs de SaaS en production.

- documentation and public product ladder
- Cloud MVP 0.2 as public proof
- static public website actions
- buyer products

Documentation-only roadmap; no application behavior is changed.

## Owner / audience

Owner: engineering and product leadership. Audience: engineers, enterprise architects, partners, and investors.

## What is ready

- Repository documentation cleanup is in scope.
- Public Cloud MVP 0.2 is documented as a static proof.

## What is not ready

- Production SaaS, backend, multi-tenant persistence, auth/SSO, production model gateway, SOC 2 readiness, enterprise integrations, billing automation, and production Proof Graph.

## Safe-boundary language

GoalOS does not modify base AI models. GoalOS improves workflows around AI through instructions, prompts, memory, scorecards, proof records, evaluations, approvals, versions, monitoring, and rollback.

GoalOS ne modifie pas les modèles IA de base. GoalOS améliore les flux autour de l’IA grâce aux instructions, prompts, mémoire, grilles de score, dossiers de preuve, évaluations, approbations, versions, surveillance et rollback.
