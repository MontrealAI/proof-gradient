# Proof Gradient Proof Archive

The Proof Archive gives every proof its own permanent webpage and evidence JSON.

## Current pages

- `/` — Main command center
- `/proofs/` — Proof archive index
- `/proofs/001-sovereign-swarm.html` — Proof #1
- `/proofs/002-evolution-tournament.html` — Proof #2
- `/proofs/003-recursive-evolution-ladder.html` — Proof #3

## Operating law

```text
No proof, no evolution.
No eval, no propagation.
No rollback, no release.
```

## Why this matters

A single page can be overwritten. A proof archive preserves history.

Each proof is:

- separately addressable
- connected to the main page
- backed by JSON evidence
- checksumed
- tested before deployment
