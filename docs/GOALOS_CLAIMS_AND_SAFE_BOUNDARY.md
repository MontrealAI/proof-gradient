# GoalOS Claims and Safe Boundary

GoalOS safe boundary: GoalOS does not modify base AI models. GoalOS improves workflows around AI through instructions, prompts, memory, scorecards, proof records, evaluations, approvals, versions, monitoring, and rollback.

GoalOS prohibited claims: guaranteed ROI, guaranteed revenue, guaranteed productivity, legal advice, tax advice, compliance certification, AI safety certification, autonomous AGI, base-model self-modification, uncontrolled recursive deployment.

$JOBS prohibited claims: investment, profit, yield, revenue share, passive income, price target, guaranteed resale value, guaranteed non-security, audited if not audited, mainnet-ready if not mainnet authorized, founder timelock/no-sale if not actually implemented, legal/tax approval if not completed.

Safe $JOBS public language: $JOBS is the native coordination asset for proof-based AI workflow work on Base. $JOBS is built for utility, coordination, and proof — not investment promises.
