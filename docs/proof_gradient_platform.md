# Proof Gradient Platform

**One agent tries. Proof decides. The network evolves.**

Proof Gradient is the agent evolution protocol where every run leaves proof, every proof selects intelligence, and every selected artifact evolves the network.

- The **Artifact Vault** stores reusable intelligence.

## Grand simplification

```text
Artifact → Run → Proof → Selection
```

Everything that can improve is an artifact. Every job creates a run. Every run creates proof. Every proof can create a candidate improvement. Every candidate improvement must pass selection.
