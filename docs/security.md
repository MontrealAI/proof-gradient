# Security and Governance

## Core rule

A model may request a tool. A plan may require a tool. A skill may describe tool use. But only policy and permissions can authorize execution.

## Permission classes

- read
- draft
- write
- send
- delete
- publish
- payment
- deploy
- external_contact
- secret_access
- admin_change

## Non-negotiables

- No tool executes without permission.
- No private data silently becomes shared intelligence.
- Every network/global artifact must be redacted, scoped, approved, and rollbackable.
- Every release must have a rollback target.
- No eval, no propagation.
