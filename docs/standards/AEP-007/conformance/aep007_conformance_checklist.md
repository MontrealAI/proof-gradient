# AEP-007 Conformance Checklist

## Level 0 - Informal public proof
- [ ] Public claim exists.
- [ ] Claim boundary exists.
- [ ] No obvious private leakage.

## Level 1 - Basic public-safe report
- [ ] Manifest exists.
- [ ] Public Claim Matrix exists.
- [ ] Evidence Summary exists.
- [ ] Limitations exist.
- [ ] Final Claim Boundary exists.

## Level 2 - Reviewed public-safe report
- [ ] Redaction Ledger exists.
- [ ] Publication Approval exists.
- [ ] Private/protected evidence is not public.

## Level 3 - Operational public-safe report
- [ ] Source docket refs exist.
- [ ] ProofPacket refs exist.
- [ ] Evaluation Summary exists.
- [ ] Rollback / Recovery Summary exists.
- [ ] Correction Policy exists.
- [ ] Public Artifact Links exist.

## Level 4 - Institutional public-safe report
- [ ] Disclosure Review exists.
- [ ] Redaction audit passes.
- [ ] Challenge window exists.
- [ ] Correction / retraction history exists.
- [ ] Report hash validates.
- [ ] Audit export is possible.

## Level 5 - Sovereign / regulated public-safe report
- [ ] Jurisdiction recorded.
- [ ] Retention policy recorded.
- [ ] Protected-boundary review completed.
- [ ] Responsible disclosure controls exist.
- [ ] Authorized publication approvers recorded.
- [ ] Challenge / retraction governance exists.
- [ ] Accessibility profile exists.
- [ ] Machine-readable bundle exists.
