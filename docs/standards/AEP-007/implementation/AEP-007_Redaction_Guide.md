# AEP-007 Redaction Guide

## Always remove from public reports

- credentials
- API keys
- private keys
- secrets
- raw prompts
- full traces
- protected personal data
- private tool logs
- security vulnerabilities before responsible disclosure
- privileged legal analysis

## Safer replacements

- public-safe summary
- source hash
- evidence reference
- private appendix reference
- redaction reason
- disclosure class
