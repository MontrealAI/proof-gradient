# AEP-004 Conformance Checklist

## Level 0 — Informal selection

- [ ] Candidate is described.
- [ ] Decision is stated.
- [ ] Evidence is referenced.
- [ ] Reason is stated.

## Level 1 — Basic Selection Gate

- [ ] Candidate object exists.
- [ ] Decision record exists.
- [ ] Evidence Docket reference exists.
- [ ] Claim boundary exists.

## Level 2 — Evaluated Selection Gate

- [ ] Required eval status recorded.
- [ ] Risk status recorded.
- [ ] Rollback target recorded.
- [ ] Policy refs recorded.

## Level 3 — Operational Selection Gate

- [ ] Gate policy exists.
- [ ] Canary plan exists where needed.
- [ ] Monitoring plan exists.
- [ ] Approval record exists.
- [ ] Challenge record exists.
- [ ] Claim boundary is explicit.

## Level 4 — Institutional Selection Gate

- [ ] Selection Certificate exists.
- [ ] Certificate hash validates.
- [ ] Rollback readiness is confirmed.
- [ ] Public/private evidence boundary is respected.
- [ ] Expiration and review_after are recorded.
- [ ] Audit export is possible.

## Level 5 — Sovereign / Regulated Selection Gate

- [ ] Jurisdiction recorded.
- [ ] Protected-boundary classification recorded.
- [ ] Retention policy recorded.
- [ ] Authorized approvers recorded.
- [ ] Evaluator attestations recorded.
- [ ] Challenge window recorded.
- [ ] Public-safe report controls exist.
