# AEP-004 Security and Privacy Guide

A Selection Gate must not force private or protected evidence into public view.

Use public-safe summaries, hashes, and evidence references.

## Do not expose

- secrets
- credentials
- sensitive personal data
- regulated data
- private prompts
- full protected traces
- critical infrastructure details
- privileged analysis

## Public certificate principle

A public Selection Certificate may say that restricted evidence was reviewed without exposing that evidence.

## High-risk decision principle

Under uncertainty, reduce scope, request evidence, reject, or roll back.
