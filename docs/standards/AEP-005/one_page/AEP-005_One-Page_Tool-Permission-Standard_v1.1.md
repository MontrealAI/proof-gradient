# AEP-005 — Tool Permission Standard

## One-page brief

AEP-005 defines the Tool Permission Standard: scoped, approved, leased, revocable, and provable tool use.

AEP-001 defines the protocol.  
AEP-002 defines the docket.  
AEP-003 defines the packet.  
AEP-004 defines the gate.  
AEP-005 defines the permission.

## Canonical law

No tool without permission.  
No action without scope.  
No high-risk tool without approval.  
No side effect without receipt.  
No irreversible action without rollback or compensation.  
No permanent authority without expiration.  
No proof, no evolution.

## Permission classes

none, read, draft, transform, write, execute, external_contact, send, delete, deploy, payment, secret_access, admin_change, protected_operation, break_glass.

## Core objects

Tool Manifest, Tool Permission Policy, Tool Request, Tool Permission Decision, Permission Lease, Approval Receipt, Tool Call Receipt, Revocation Receipt, Compensation Receipt, Break-Glass Request.

## Public line

GoalOS allows only what is scoped, approved, leased, revocable, and provable.
