Extract this package into:

`docs/standards/AEP-005/`

Then copy:

`.github/workflows/add-aep005-tool-permission-standard-page.yml`

to:

`.github/workflows/add-aep005-tool-permission-standard-page.yml`

Actions → Add AEP-005 Tool Permission Standard Website Page → Run workflow

`https://montrealai.github.io/proof-gradient/standards/AEP-005/`
