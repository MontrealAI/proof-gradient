# AEP-008 Role Separation Profile

## Minimum separation

The operator should not be the only approver.

## Institutional separation

- Operator executes work.
- Reviewer reviews evidence.
- Gatekeeper issues selection.
- Approver authorizes promotion.
- Redactor approves public-safe publication.
- Auditor reviews room integrity.

## High-risk invariant

No single role should both execute high-risk work and approve its promotion.

## Exception handling

If separation is not possible, the room must record:

- exception reason
- compensating control
- approver
- expiry
- public/private boundary
