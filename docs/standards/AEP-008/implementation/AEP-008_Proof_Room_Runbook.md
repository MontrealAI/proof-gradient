# AEP-008 Proof Room Runbook

## Open

- Create manifest.
- Approve charter.
- Assign roles.
- Define scope.
- Define evidence boundary.

## Operate

- Intake work items.
- Execute bounded runs.
- Collect ProofPackets.
- Assemble Evidence Dockets.
- Review evals and risks.
- Record decisions.

## Decide

- Use Selection Gate.
- Record Selection Certificate.
- Confirm Tool Permissions.
- Confirm Rollback Receipts.

## Publish

- Generate Public-Safe Proof Report.
- Redact private/protected evidence.
- Approve publication.
- Record correction policy.

## Close

- Export audit bundle.
- Record closure report.
- Archive evidence.
- Feed reusable artifacts back into the system.
