# AEP-008 Conformance Checklist

## Level 0 — Informal Proof Room

- [ ] Mission described.
- [ ] Participants listed.
- [ ] Evidence links listed.
- [ ] Decisions recorded.

## Level 1 — Basic Proof Room

- [ ] Manifest exists.
- [ ] Charter exists.
- [ ] Scope boundary exists.
- [ ] Role registry exists.
- [ ] Evidence boundary exists.
- [ ] Work item registry exists.

## Level 2 — Operational Proof Room

- [ ] Evidence Docket register exists.
- [ ] ProofPacket register exists.
- [ ] Tool Permission register exists.
- [ ] Decision log exists.
- [ ] Room session records exist.

## Level 3 — Institutional Proof Room

- [ ] Selection Gate register exists.
- [ ] Rollback register exists.
- [ ] Public Report register exists.
- [ ] Separation of duties is required.
- [ ] Audit export exists.
- [ ] Closure report exists.

## Level 4 — Regulated Proof Room

- [ ] Protected evidence boundary exists.
- [ ] Retention policy recorded.
- [ ] Jurisdiction recorded.
- [ ] Authorized approvers recorded.
- [ ] Independent review recorded.
- [ ] Audit export supports review.

## Level 5 — Sovereign Proof Room

- [ ] Sovereign jurisdiction boundary recorded.
- [ ] Public/private/protected evidence controls recorded.
- [ ] Public-institution roles recorded.
- [ ] Policy traceability recorded.
- [ ] Public-safe reporting controls recorded.
- [ ] Sovereign archive requirements recorded.
