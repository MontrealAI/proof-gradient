# Install AEP-008 in proof-gradient

## Recommended placement

Extract this package into:

`docs/standards/AEP-008/`

Then copy:

`.github/workflows/add-aep008-proof-room-standard-page.yml`

to:

`.github/workflows/add-aep008-proof-room-standard-page.yml`

## Run website workflow

Go to:

Actions → Add AEP-008 Proof Room Standard Website Page → Run workflow

This should create:

`https://montrealai.github.io/proof-gradient/standards/AEP-008/`

AEP-008 is additive.

Do not remove AEP-001 through AEP-007.  
Do not remove existing proof pages.
