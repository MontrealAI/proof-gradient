# AEP-006 Conformance Checklist

## Level 0 — Informal rollback note
- [ ] Rollback is described.
- [ ] Trigger is described.
- [ ] Owner is listed.

## Level 1 — Rollback plan
- [ ] Rollback target exists.
- [ ] Baseline exists.
- [ ] Owner exists.
- [ ] Steps exist.
- [ ] Verification plan exists.

## Level 2 — Rollback receipt
- [ ] Rollback Receipt exists.
- [ ] Status exists.
- [ ] Scope exists.
- [ ] Evidence refs exist.
- [ ] Hash validates.

## Level 3 — Verified rollback
- [ ] Rollback Verification exists.
- [ ] Tests/evals/monitoring refs exist.
- [ ] Restored baseline confirmed.
- [ ] Residual risk recorded.

## Level 4 — Institutional rollback
- [ ] Authorization exists.
- [ ] Evidence Docket refs exist.
- [ ] ProofPacket refs exist.
- [ ] Selection Certificate refs exist.
- [ ] Tool receipt refs exist.
- [ ] Compensation path exists.
- [ ] Public/private boundary exists.
- [ ] Post-Rollback Review exists.

## Level 5 — Sovereign / regulated rollback
- [ ] Jurisdiction recorded.
- [ ] Retention policy recorded.
- [ ] Protected-boundary classification recorded.
- [ ] Authorized approvers recorded.
- [ ] Public-safe controls exist.
- [ ] Affected-public notice rules exist.
- [ ] Audit export possible.
