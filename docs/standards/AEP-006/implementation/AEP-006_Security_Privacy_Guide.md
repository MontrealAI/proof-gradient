# AEP-006 Security and Privacy Guide

A public rollback receipt should prove recovery without leaking private or protected intelligence.

## Never publish by default

- secrets
- private prompts
- sensitive traces
- customer data
- protected infrastructure details
- privileged analysis
- vulnerability details

## Publish instead

- rollback occurred
- scope affected
- baseline restored
- verification status
- residual risk
- claim boundary
- public-safe evidence summary
