# AEP-006 Recovery Runbook

## Before release

- Define rollback target.
- Define rollback owner.
- Define rollback trigger.
- Define verification steps.
- Define compensation path.
- Store release Evidence Docket.

## During incident

1. Freeze scope.
2. Record trigger.
3. Request rollback.
4. Authorize rollback.
5. Execute rollback.
6. Record receipt.
7. Verify restoration.
8. Notify if required.
9. Review and improve.

## After rollback

- Publish public-safe report if allowed.
- Update evals.
- Update tool permissions.
- Update Selection Gate policy.
- Update artifacts.
