# Sovereign Swarm

**A deterministic large multi-agent coordination lattice.**

The Sovereign Swarm coordinates 96 specialized agents across eight divisions:

- Direction Council
- Strategy Foundry
- Capability Guild
- Proof Court
- Selection Senate
- Governance Shield
- Capital Engine
- Energy Horizon Cell

The swarm records:

- agent roster
- divisional roles
- handoffs
- votes
- trace events
- consensus
- selection decision
- rollback target

This proves multi-agent coordination inside the repository. It does not claim external LLM deployment unless future provider-backed agents are connected and traced.
