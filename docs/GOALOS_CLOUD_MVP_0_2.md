# GoalOS Cloud MVP 0.2

## English summary

GoalOS Cloud MVP 0.2 is a public static proof of the Workflow Studio, Execution Engine, Evaluation Engine, Proof Room, Improvement Engine, Approval, Versioning, and Rollback flow.

## Résumé français

GoalOS Cloud MVP 0.2 est une preuve statique publique du studio de flux, du moteur d’exécution, du moteur d’évaluation, de la Salle de preuve, du moteur d’amélioration, de l’approbation, du versionnement et du rollback.

## Current status

## What is ready

- Public demo is documented as a static proof.
- Architecture modules are listed.
- No secrets or production backend are required for the public proof.

## What is not ready

- No production backend yet.
- No multi-tenant persistence, SSO, billing automation, or production model gateway yet.

## Safe-boundary language

GoalOS does not modify base AI models. GoalOS improves workflows around AI through instructions, prompts, memory, scorecards, proof records, evaluations, approvals, versions, monitoring, and rollback.

GoalOS ne modifie pas les modèles IA de base. GoalOS améliore les flux autour de l’IA grâce aux instructions, prompts, mémoire, grilles de score, dossiers de preuve, évaluations, approbations, versions, surveillance et rollback.
