# Install AEP-006 in proof-gradient

Extract this package into:

`docs/standards/AEP-006/`

Then copy:

`.github/workflows/add-aep006-rollback-receipt-standard-page.yml`

to:

`.github/workflows/add-aep006-rollback-receipt-standard-page.yml`

Run:

Actions → Add AEP-006 Rollback Receipt Standard Website Page → Run workflow

This should create:

`https://montrealai.github.io/proof-gradient/standards/AEP-006/`

AEP-006 is additive. Do not remove AEP-001 through AEP-005 or existing proof pages.
