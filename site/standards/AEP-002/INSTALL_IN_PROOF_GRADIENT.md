# Install AEP-002 in proof-gradient

## Recommended non-technical path

1. Extract this package.
2. Upload the extracted files into:

   `docs/standards/AEP-002/`

3. Copy the workflow files into:

   `.github/workflows/`

4. Run:

   `Actions → Add AEP-002 Evidence Docket Standard Website Page → Run workflow`

5. Run:

   `Actions → AEP-002 Official Release → Run workflow`

Use tag:

`aep-002-v1.1`

## Safe rule

AEP-002 is additive.

Do not remove AEP-001.  
Do not remove existing proof pages.  
Do not overwrite the website wholesale.
