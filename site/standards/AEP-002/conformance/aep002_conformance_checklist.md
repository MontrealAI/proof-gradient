# AEP-002 Conformance Checklist

## Level 0 — Informal proof
- [ ] Goal is stated.
- [ ] Output is summarized.
- [ ] Evidence is listed.
- [ ] Checks/evals are listed.
- [ ] Claim boundary exists.

## Level 1 — Basic Evidence Docket
- [ ] Manifest exists.
- [ ] Claims matrix exists.
- [ ] Commitment record exists.
- [ ] Execution summary exists.
- [ ] Evidence inventory exists.
- [ ] At least one evaluation or explicit evaluation gap exists.
- [ ] Rollback plan exists.
- [ ] Claim boundary exists.

## Level 2 — Operational Evidence Docket
- [ ] Tool-use ledger exists.
- [ ] Policy/approval ledger exists.
- [ ] Cost and latency ledger exists.
- [ ] Risk ledger exists.
- [ ] Selection decision exists.
- [ ] Public/private boundary exists.

## Level 3 — Institutional Evidence Docket
- [ ] Selection Certificate exists.
- [ ] Canary plan exists.
- [ ] Monitoring plan exists.
- [ ] Rollback target exists.
- [ ] Audit export exists.
- [ ] Public-safe report exists.

## Level 4 — Sovereign / Regulated Evidence Docket
- [ ] Public/private/protected classification exists.
- [ ] Retention policy exists.
- [ ] Jurisdiction is recorded.
- [ ] Authorized data boundary is recorded.
- [ ] Evaluator attestations exist.
- [ ] Restricted appendix controls exist.
