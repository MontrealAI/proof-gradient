## Purpose

AEP-001 defines the GoalOS Proof-of-Evolution Constitution: a protocol standard for turning AI-agent work into governed, reusable, auditable institutional capability.

The architecture is built around four core systems:

1. **Artifact Vault** — stores reusable intelligence.
2. **Run Fabric** — executes agents at scale.
3. **Proof Ledger** — records what happened.
4. **Selection Gate** — promotes only what proved itself.

## Public-Private Proof Boundary

AEP-001 separates private intelligence from public proof.

Private execution may contain sensitive prompts, tools, traces, customer data, model details, or enterprise context.

Public proof should contain commitments, artifact identifiers, hashes, proof packets, evaluator attestations, selection certificates, rollback receipts, and claim boundaries.

## Evidence Docket Standard

The Evidence Docket is the standard unit of institutional proof. It records:

- manifest
- claims matrix
- task specification
- environment
- baselines
- proof packets
- replay instructions
- cost ledger
- risk ledger
- policy ledger
- evaluator attestations
- selection certificate
- canary plan
- rollback plan
- public-safe report
- private audit appendix

## Claim Boundary

AEP-001 does not claim achieved AGI, ASI, superintelligence, guaranteed ROI, legal advice, financial advice, safety certification, external customer production results, energy abundance, or Kardashev Type II achievement.

It defines a protocol architecture and falsifiable research program for governed agent evolution.
