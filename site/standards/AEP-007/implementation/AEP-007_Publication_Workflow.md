# AEP-007 Publication Workflow

1. Draft report.
2. Map source dockets and ProofPackets.
3. Classify disclosures.
4. Draft public claims.
5. Run redaction audit.
6. Add claim boundary.
7. Obtain publication approval.
8. Publish report.
9. Open challenge window.
10. Issue corrections or retractions when needed.
11. Archive history.
