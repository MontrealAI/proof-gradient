# AEP-005 Conformance Checklist

## Level 0 — Informal tool note
- [ ] Tool use is described.
- [ ] Risk is described.
- [ ] Human review status is described.

## Level 1 — Tool manifest
- [ ] Tool manifest exists.
- [ ] Permission classes supported are listed.
- [ ] Default permission is defined.
- [ ] Risk class is defined.
- [ ] Owner is defined.

## Level 2 — Gateway decision
- [ ] Tool request exists.
- [ ] Tool Permission Decision exists.
- [ ] Decision hash validates.
- [ ] Decision is allow, deny, or approval_required.

## Level 3 — Scoped leased permission
- [ ] Tenant scope exists.
- [ ] Workflow scope exists.
- [ ] Run scope exists.
- [ ] Time scope exists.
- [ ] Data class scope exists.
- [ ] Environment scope exists.
- [ ] Permission lease exists.
- [ ] Lease expiration exists.

## Level 4 — Institutional permission
- [ ] High-risk permissions require approval.
- [ ] Tool Call Receipt exists.
- [ ] ProofPacket reference exists.
- [ ] Evidence Docket reference exists.
- [ ] Rollback or compensation plan exists where required.
- [ ] Revocation path exists.
- [ ] Audit export is possible.

## Level 5 — Sovereign / regulated permission
- [ ] Jurisdiction recorded.
- [ ] Retention policy recorded.
- [ ] Protected data boundary recorded.
- [ ] Authorized approvers recorded.
- [ ] Separation of duties recorded.
- [ ] Public/private/protected evidence boundary enforced.
- [ ] Break-glass use requires review.
